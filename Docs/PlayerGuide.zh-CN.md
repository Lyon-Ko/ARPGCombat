# 剑斗演示：试玩说明

本说明依据当前 `Docs/Architecture.md`、`ACombatCharacter` 输入与战斗接口、HUD 和技能生成脚本编写。它说明当前实现和配置的操作方式，不代表所有招式、美术与验收场景已经通过最终实机验收。

## 在编辑器中启动

1. 使用 Unreal Engine 5.8.2 打开 `D:/UEproject/Combat/Combat.uproject`。
2. 默认启动地图和游戏地图均已配置为 `/Game/Combat/Maps/L_CombatArena`，默认 GameMode 为 `/Game/Combat/Blueprints/BP_CombatGameMode`，分屏已关闭。若编辑器恢复了旧会话，请手动打开战斗竞技场。
3. 点击编辑器工具栏的“运行 / Play”，使用单人 PIE。点击游戏视口，使键盘与鼠标输入进入游戏。
4. 看到玩家、Boss 和中文血条后开始。按 `Esc` 结束 PIE；需要把鼠标交还编辑器时可使用 `Shift + F1`。

## 键位

| 操作 | 按键 |
| --- | --- |
| 移动 | W、A、S、D |
| 转动自由镜头 | 鼠标移动 |
| 普通攻击 / 连击 / 状态派生 | 鼠标左键 |
| 瞬时精准格挡 | 鼠标右键，单次按下 |
| 短冲 | 左 Shift |
| 跳跃 / 二段跳 | 空格，再按一次可二段跳 |
| 锁定或解除 Boss | Q |
| 暂停 / 继续 | P |
| 胜负结算后再战 | R |

没有耐力条，也没有按住右键持续防御。技能动作期间，移动、跳跃或取消可能受当前招式窗口限制。

## 四段连击与短冲斩

在地面点击左键发动第一剑，在连段允许的时机再次点击，依次接第二、第三、第四剑。输入是逐次点击，不会因为长按左键自动打完整套。当前输入缓冲为约 0.18 秒；过早或过晚的输入不一定能接上下一段。

按住移动方向并按左 Shift，可沿八方向短冲。未输入方向时默认后撤；自由镜头下按镜头方向判定，锁定时按相对目标方向判定。当前配置的短冲距离约 2.5 米，动作约 0.23 秒，冷却约 0.35 秒；无敌只覆盖动作的一段时间，不能把整段短冲都当作无敌。

短冲状态中按左键可派生短冲斩。HUD 的“短冲：就绪 / 恢复中”用于判断是否能够再次使用。

## 瞬时格挡与反击

面对即将命中的攻击，短按右键。有效窗口约 0.20 秒，覆盖正前方约 140°；背后的攻击不能靠正面格挡挡住。按住右键不会延长窗口，也不会自动反复发动。

格挡成功时会出现“精准格挡”和“反击就绪 · 左键”。在约 0.8 秒内点击左键，可发动反击派生。若提示消失，需要再次成功格挡获得反击机会。格挡有恢复间隔，成功格挡可以清除当前格挡冷却，以应对下一次来袭。

## 空中派生

空格起跳后，点击左键发动空中第一剑，再次点击可接空中第二剑。同一次离地期间最多两次空中攻击和一次空中短冲；落地后重置。

在空中按住左键超过约 0.28 秒，会请求下劈派生；能否立即衔接仍取决于当前动作的取消或连段窗口。下劈朝地面释放，适合在落点附近收尾。二段跳、短冲与空中剑技可以组合，但动作忙碌时不能随意起跳。

## 观察 Boss 与战斗结果

Boss 具有三连剑击、蓄力范围爆发、前冲斩，以及左右或后跳释放剑气等招式。观察动作预备和地面预警，选择拉开距离、短冲避开或在允许格挡的命中前准确格挡。范围爆发高度会覆盖普通跳跃范围，单纯跳起不保证安全。Boss 半血后的第二阶段会在当前招式结束后切换。

HUD 显示双方生命值、Boss 韧性和阶段。“破韧”提示代表出现进攻机会。玩家生命归零时显示失败，Boss 生命归零时显示胜利；结算后按 R 重置双方位置、生命和战斗状态。战斗尚未结束时 R 不会强制重开。

暂停后可使用现有设置项调整音量、镜头灵敏度和镜头震动；按 P 继续。再次试玩时若仍处于编辑器输入状态，先点击 PIE 视口。

锁定时侧移与后退保持朝向目标，自由镜头鼠标转向只在解除锁定后生效。墙边镜头会回缩；距离本地玩家中心小于约 220cm 时，玩家模型与自身武器仅对拥有者视角隐藏，距离大于约 270cm 时恢复，避免身体遮满画面。Boss、碰撞和受击不因此隐藏或关闭，死亡/重试会恢复原可见状态。这是近镜头保护，并非角色消失或无敌。

## 当前说明的边界

当前角色为原生骨架 Kwang（玩家）和 Greystone（Boss）。角色蓝图位于 `/Game/Combat/Characters/BP_CombatPlayer`、`BP_CombatBoss`；2D 动画蓝图分别为 `/Game/Combat/Animations/Native/Kwang/ABP_CombatKwang2D` 和 `/Game/Combat/Animations/Native/Greystone/ABP_CombatGreystone2D`。最终技能 Montage 以各角色 Native 子目录下的 `AM_Attack1`、`AM_Boss_AOE` 等为准，不使用早期 Manny 模板作为当前绑定说明。
