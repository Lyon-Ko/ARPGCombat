# 战斗技能工作台 V1

**动画技能已接入原生 Montage。** 新制作和迁移流程见 [原生 Montage 技能编排](NativeMontageSkills.zh-CN.md)。下文的自定义时间轴主要用于无动画技能，以及尚未迁移的 V1 数据格式说明。

面向设计人员的 UE 内置技能编辑器。入口是 **工具 → 战斗技能工作台**，或双击技能、子弹、Buff、技能集合资产。新技能通过数据时间轴执行；原有 GA 蓝图和 Montage 通知技能保持兼容。

## 十分钟创建一个技能

1. 在工作台点 **＋ 技能**，保存到自己的目录，例如 `/Game/Combat/Skills/Custom`。
2. 在项目设置的 Gameplay Tags 页面登记唯一标签，再回到技能参数的 `SkillTag` 中选取。仅填写资产名称不会产生技能标签。
3. 设置 `Duration`（秒）。普通动画技能选择与角色同骨架的 `Montage`；时间轴中的时间是动画资源时间，无动画技能使用本地执行时间。
4. 点 **＋ 时间轴事件**，在右侧选择事件 `Type`，设置时间、参数和关联子弹/Buff 资产。没有动画的发射或 Buff 技能也可直接运行。
5. 点 **＋ 集合**，把技能加入集合的 `Skills` 数组。需要派生的技能必须同时装备。打开集合可以看到全部技能节点。
6. 点 **检查资产**，根据提示修正。点工具栏保存；资源未保存时标签页会有脏标记。
7. 点 **PIE 试玩**：进入独立测试场景，授予集合中的技能，重置角色和靶子并释放所选技能。再次点击会重置后重播；**停止试玩**或 Esc 退出。
8. 正式接入时，在主内容浏览器选择角色蓝图，再从集合工作台点 **装备集合**。保存角色蓝图并重启 PIE。角色上的 `DesignerSkillSet` 属性也可直接指定集合。

新建的技能默认 `DataDriven=true`，使用原生数据执行器，不需要单独制作 GA 蓝图。`AbilityClass` 是旧模式入口；数据模式忽略它。

工作台中的资产编辑保存到项目；试玩授予与额外靶子、障碍物仅存在于 PIE 世界。运行期间不要同时编辑正在测试的定义；在两次试玩之间调整参数。

## 时间轴与预览

- 点击事件块在右侧编辑；拖动移动时间，拖动窗口右边缘或按住 Shift 调整长度。
- 默认吸附到 30fps 的帧格；Alt 暂时取消吸附，滚轮改变缩放。
- 时间轴获得焦点后，Ctrl+C / Ctrl+V 复制粘贴事件，Delete 删除；粘贴生成新的事件身份，位置为播放头。
- 点击刻度条调整播放头，**播放 / 暂停**循环预览动画。预览中的线框显示子弹出生碰撞形状及范围伤害半径。
- 预览拖动只采样动画，不反向恢复伤害、Buff 或物理状态。检查真实效果使用 PIE 试玩。
- 双击派生连线可编辑该规则；拖动节点会保存图位置。撤销/重做支持事件、连接、位置和资产属性。

| 事件 | 配置与行为 |
| --- | --- |
| HitWindow | 时间与长度指定近战有效区间；每次打开获得独立命中 ID，同目标在同窗口只受一次伤害。 |
| Movement | 位移方向使用角色局部方向；填写距离（cm）及持续时间。 |
| Projectile | 选择子弹资产、Socket/偏移、瞄准方式、发射图案、数量、连发次数与间隔。 |
| AreaWarning / AreaRelease | 复用技能的范围半径、高度及释放延迟；正常结束前须留足结算时间。 |
| ApplyBuff / RemoveBuff | 选择 Buff，自身/目标/敌方范围，以及是否绑定到本次技能生命周期。 |
| CancelWindow / ComboWindow | 指定可取消或衔接的时间区间；窗口关闭后恢复限制。 |
| Effect | 播放指定 Niagara 和声音。 |
| Finish | 提前正常结束。无动画技能也会在 Duration 到达时结束；动画技能通常随 Montage 完成。 |

## 技能派生、互斥和打断

从节点的 **＋ 新建派生**输出连到目标技能输入。现有连线重接会改变目标。默认规则是攻击输入派生；右侧 `Derivations` 数组也可编辑完整规则。

规则支持 `Input`、`Hit`、`Completed` 三种触发、时间窗口、标签查询、地面/空中限制、命中确认和优先级。同优先级采用数组顺序。当前技能的有效派生优先于普通输入技能选择，实际执行时再次检查冷却及条件。

输入缓冲默认沿用角色配置的 0.18 秒。过早输入会过期，不会因为等待窗口而自动延长。有效命中指实际造成伤害或击杀，闪避、格挡不算命中确认。已经结束的旧技能投射物不会触发新技能的命中派生。

现有攻击、格挡、闪避输入分别使用 `Combat.Input.Attack`、`Combat.Input.Parry`、`Combat.Input.Dash`。登记新的 InputTag 不会自动创建键位；新键位需要角色输入事件调用现有请求接口。

自动派生链有 16 次安全上限，编辑器拒绝自动派生循环；输入驱动的循环允许存在。技能完成后派生在下一次执行更新处理，保证旧 GAS 实例完成退出。

| 参数 | 含义 |
| --- | --- |
| ExclusiveTags | 与当前技能存在匹配标签时拒绝切换。 |
| BlockedByTags | 角色拥有这些标签时禁止激活。 |
| InterruptPriority / InterruptResistance | 切入技能的优先级不能低于被打断技能的抗打断级别。 |
| ForceInterrupt | 配合严格高于抗打断级别的优先级，可在取消窗口外切入。 |
| AllowedInterrupts | 允许的打断原因：技能、普通受击、格挡、破韧、控制。死亡和重试始终强制清理。 |

霸体 Buff 默认阻止普通受击打断，但不能阻止破韧、死亡和重试。旧技能仍使用原来的 `bCanInterrupt` 及窗口语义。

`RequestSkillDetailed` 返回 Activated、Buffered、MissingSkill、Dead、Cooldown、Conditions、Blocked、Uninterruptible 或 ActivationFailed。原有 `RequestSkillByTag` / `RequestSkillByInputTag` 布尔接口继续可用。底部日志显示实际请求结果、事件、派生和 Buff 处理。

底部请求日志目前使用枚举编号：0 成功、1 已缓冲、2 未装备技能、3 角色死亡、4 冷却中、5 条件不符、6 互斥/标签阻止、7 不允许打断、8 GAS 激活失败。

## 子弹和导弹

子弹资产配置独立于技能，多个技能可共用。每次发射保存运动/伤害参数快照，初始化完成后再开始碰撞检测。

- 图案：单发、扇形、环形、随机散射；散射种子可复现。`Count` 最多 128，`Bursts` 最多 64。
- 运动：直线、重力抛射、制导；配置速度、加速、最大速度、寿命和最大飞行距离。
- 碰撞：球或盒，扫掠检测，出生重叠处理；忽略发射者和同阵营角色，世界阻挡可配置反弹，角色命中可配置穿透。
- `Penetrations=1` 表示命中第一个敌人后继续，第二个敌人处终止；一个飞行实体对同一角色只命中一次。
- `Bounces` 控制世界反弹次数。命中会调用现有格挡、闪避、生命/韧性和死亡路径。
- 爆炸支持半径与边缘伤害比例，并检查遮挡；默认启用爆炸时不叠加直击伤害，`StackDirectAndExplosion` 可显式开启。
- `HitBuff` 仅对实际受伤且仍存活的对象应用。到期、距离耗尽、技能清理、死亡和重试不会伪造命中爆炸。
- 导弹支持延迟制导、角速度限制、目标运动预测、近炸和搜索范围/视锥。丢失目标可选择直飞、自毁或按间隔重新搜索。
- `DestroyOnInterrupt` 默认开启；正常完成允许已释放子弹继续飞行。死亡、重试和退出 PIE 始终清理。

PIE 工具栏的 **移动靶开关**让靶子横向移动；**＋ 靶子**、**＋ 障碍**可验证穿透和遮挡。新增对象为临时试玩对象。

## Buff

Buff 使用 GAS 效果句柄恢复属性与标签，不用手工减回旧数值。

- 持续方式：Instant（瞬时）、Timed（限时）、Infinite（无限，需主动移除）。
- 叠层：最大层数、是否区分来源、刷新持续时间、重置周期。同资产/来源/技能作用域决定叠层分组。
- 常用参数：伤害倍率、移速倍率、最大生命/韧性加值、霸体、授予标签。
- `AttributeModifiers` 可选择 GAS 属性并配置加值及乘数。常用快捷字段与通用修改器会共同生效，避免重复填写同一效果。
- `HealthPerPeriod` 正数治疗、负数持续伤害，每层每周期生效；瞬时 Buff 立即执行一次。持续伤害有来源记录并进入角色死亡清理。
- `InterruptOnApply` 请求 Control 原因打断；目标拒绝该原因时拒绝此 Buff。
- `SkillScoped` 效果随来源技能结束清理，即使施加在另一个目标身上；非技能作用域效果在动作结束后继续存在。
- 死亡和重试清除目标全部 Buff。无限 Buff 不会跨重试残留。

瞬时效果的属性变化不会被撤销；瞬时 Buff 不提供持续标签或霸体。持续属性乘算遵循 GAS 聚合规则；同实例叠层倍率按每层幂次生成。

## 示例、兼容与验证

`/Game/Combat/SkillEditorExamples` 包含技能集合、六个示例技能、穿透弹/反弹弹/制导爆炸导弹，以及灼烧、减速、增伤、霸体 Buff。前三个技能展示攻击输入链，第二段要求已命中才允许派生。测试地图为 `L_SkillEditorTest`。

基础生成 pipeline 不会覆盖此目录。`Tools/editor/generate_skill_editor_examples.py` 仅创建缺失的示例与地图，已有资源不会被重写。

**复制为新版**只复制资产和转换已知 Montage Notify：位移、近战开闭、发射、预警、范围释放、连招、取消和结束。新副本清空 SkillTag，必须登记新标签；发射事件必须选择子弹定义。自定义 GA 蓝图逻辑不会自动翻译，也不会静默修改源资产。

旧 `NextSkillTag` 转成一条输入派生规则，目标仍指向原后继，需要检查集合是否包含该目标。新版运行不再读取旧的单后继字段。

自动化入口：

```powershell
.\Tools\Combat.ps1 build
.\Tools\Combat.ps1 editor
.\Tools\Combat.ps1 python -File Tools/editor/generate_skill_editor_examples.py
```

编辑器控制台执行 `Automation RunTests Combat.SkillEditor` 验证资产、工厂和图事务。已启动独立 PIE 后，使用 `Tools/tests/skill_editor_regression.py` 的 `start/status/stop` 非阻塞入口验证运行时；不要同时运行其他对局测试。

首版沿用单人 LocalOnly GAS 和当前二阵营判定，不包含多人预测/复制。动画预览不提供逆向物理回放。验证结果及未覆盖范围见 [本次交付记录](SkillEditorVerification.md)。
